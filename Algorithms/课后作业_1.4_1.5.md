## 1.4.4 TwoSum 的频率表



### 答：



```java
int n = a.length;
int count = 0;
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (a[i] + a[j] == 0) {
            count++;
        }
    }
}
```

令：

- A：方法体，执行 1 次；
- B：外层循环体，执行 `n` 次；
- C：内层循环体，执行 $\binom{n}{2}$ 次；
- D：`if` 语句的执行次数，最多为 $\binom{n}{2}$，具体取决于输入。

| 语句块 | 单次耗时 | 执行次数 | 总耗时 |
|---|---:|---:|---:|
| D：`count++` | $t_0$ | $x$ | $t_0x$ |
| C：判断 `if` | $t_1$ | （n²-n）/2 | $t1（（n²-n）/2）$ |
| B：外层循环 | $t_2$ | $n$ | $t_2n$ |
| A：其他语句 | $t_3$ | 1 | $t_3$ |

所以

$$
T(n)=t_1（（n²-n）/2）+t_2n+t_3+t_0x.
$$

忽略低阶项后：

$$
T(n)\sim \frac{t_1}{2}n^2.
$$

因此 `TwoSum` 的运行时间为 $\Theta(n^2)$。

## 1.4.5 Tilde 近似



给出下列表达式的渐近等价式：

1. $n+1$
2. $1+1/n$
3. $(1+1/n)(1+2/n)$
4. $2n^3-15n^2$
5. $\lg(2n)/\lg n$
6. $\lg(n^2+1)/\lg n$
7. $n^{100}/2^n$

### 答

利用定义：$f(n)\sim g(n)$ 表示 $f(n)/g(n)\to 1$。

1. 
   $$n+1\sim n.$$
   因为 $1/n\to 0$。

2. 
   $$1+\frac1n\sim 1.$$

3. 
   $$\left(1+\frac1n\right)\left(1+\frac2n\right)\sim 1.$$

4. 
   $$2n^3-15n^2\sim 2n^3.$$

5. 
   $$\frac{\lg(2n)}{\lg n}=1+\frac1{\lg n}\sim 1.$$

6. 因为 $\lg(n^2+1)\sim\lg(n^2)=2\lg n$：
   $$\frac{\lg(n^2+1)}{\lg n}\sim 2.$$

7. 指数函数最终超过任意固定次数的多项式，但该表达式本身不是一个可删掉低阶项的和。其精确的表达式仍为
   $$\frac{n^{100}}{2^n}.$$

## 1.4.6 三段循环的增长量级


分析下面 3 段代码中 `sum++` 的执行次数。

```java
// (a)
for (int k = n; k > 0; k /= 2)
    for (int i = 0; i < k; i++)
        sum++;

// (b)
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;

// (c)
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < n; j++)
        sum++;
```

### 答

#### (a)



$$
\sum_{r\ge 0}\frac{n}{2^r}<2n.
$$

因此为线性增长：

$$\boxed{\Theta(n)}.$$

#### (b)

外层取值为 $1,2,4,\ldots,2^m<n$，内层执行次数等于当前 `i`：

$$
1+2+4+\cdots+2^{m-1}=2^m-1=\Theta(n).
$$

因此：

$$\boxed{\Theta(n)}.$$

#### (c)

外层执行 $\Theta(\lg n)$ 次，每次内层执行 `n` 次：

$$
n\cdot\lg n.
$$

因此：

$$\boxed{\Theta(n\lg n)}.$$

## 1.4.7 ThreeSum 的算术运算成本



### 答

`ThreeSum` 枚举所有满足 $i<j<k$ 的下标三元组。三元组的数量为

$$
\binom{n}{3}=\frac{n(n-1)(n-2)}{6}.
$$

对每个三元组：

- 计算 `a[i] + a[j] + a[k]` 需要 2 次加法；
- 与 0 比较需要 1 次比较。



$$
3\binom{n}{3}\sim \frac12 n^3
$$


循环下标比较和自增的总成本也是 $O(n^3)$，只会改变常数，不改变数量级。因此总成本为

$$
\boxed{\Theta(n^3)}.
$$



## 1.4.8 统计相等数对



给定一个输入文件，统计其中值相等的数对数量。先给出平方时间方法，再利用 `Arrays.sort()` 设计线性对数时间方法。

### 答



#### 

1. 使用 `Arrays.sort(a)` 将数组排序；
2. 排序后相等的值一定连续；
3. 若某个值连续出现 $f$ 次，它贡献的相等数对为
   $$\binom{f}{2}=\frac{f(f-1)}{2};$$
4. 扫描每个连续段并累加。



```java
Arrays.sort(a);
long count = 0;
int i = 0;
while (i < a.length) {
    int j = i + 1;
    while (j < a.length && a[j] == a[i]) {
        j++;
    }
    long frequency = j - i;
    count += frequency * (frequency - 1) / 2;
    i = j;
}
```

排序需要 $\Theta(n\lg n)$，扫描需要 $\Theta(n)$，总复杂度为

$$
\boxed{\Theta(n\lg n)}.
$$





## 1.4.15 Faster 3-sum


### 答

### (1) TwoSumFaster

先排序。设左右指针分别为 `lo` 和 `hi`：

- 若 `a[lo] + a[hi] < 0`，需要更大的和，因此 `lo++`；
- 若和大于 0，需要更小的和，因此 `hi--`；
- 若和等于 0：
- 若 `a[lo] != a[hi]`，分别统计两端连续重复元素的数量，贡献为
    $$c_{lo}c_{hi};$$
  - 若 `a[lo] == a[hi]`，区间中剩余的所有元素都相同，贡献为
    $$\binom{hi-lo+1}{2},$$
    然后结束。

排序之后扫描一次，因此扫描阶段为 $\Theta(n)$；包含排序后总体为 $\Theta(n\lg n)$。

### (2) ThreeSumFaster

排序数组后，固定最左边的下标 `i`，在区间 `i+1..n-1` 内使用双指针寻找：

$$
a[i]+a[lo]+a[hi]=0.
$$



```java
Arrays.sort(a);
long count = 0;
for (int i = 0; i < a.length - 2; i++) {
    int lo = i + 1;
    int hi = a.length - 1;
    while (lo < hi) {
        long sum = (long) a[i] + a[lo] + a[hi];
        if (sum < 0) {
            lo++;
        } else if (sum > 0) {
            hi--;
        } else {
            // 无重复值时直接 count++、lo++、hi--。
            // 有重复值时统计两端连续重复段的乘积，
            // 然后跳过完整的重复段，避免漏计或重复计数。
            int loValue = a[lo];
            int hiValue = a[hi];
            long loCount = 0;
            long hiCount = 0;
            while (lo <= hi && a[lo] == loValue) {
                lo++;
                loCount++;
            }
            while (hi >= lo && a[hi] == hiValue) {
                hi--;
                hiCount++;
            }
            count += loCount * hiCount;
        }
    }
}
```

固定一个 `i` 后，双指针最多各移动 $O(n)$ 次，因此这一轮是 $O(n)$；共有 $n$ 轮：

$$
O(n)\cdot O(n)=O(n^2).
$$

排序为 $O(n\lg n)$，被平方项支配，所以总体为

$$
\boxed{\Theta(n^2)}.
$$

## 1.5.8 Quick-Find 中错误 union 的反例



说明以下直观写法为什么不正确：

```java
public void union(int p, int q) {
    if (connected(p, q)) return;
    for (int i = 0; i < id.length; i++) {
        if (id[i] == id[p]) {
            id[i] = id[q];
        }
    }
}
```

### 反例

取 3 个站点，初始：

```text
id = [0, 1, 2]
```

依次处理：

```text
0-1
0-2
```

处理 `0-1` 后：

```text
id = [1, 1, 2]
```

处理 `0-2` 时，循环开始前 `id[0] = 1`，`id[2] = 2`。

- `i=0`：`id[0] == id[p]`，把 `id[0]` 改为 2；
- `i=1`：此时 `id[1]` 仍为 1，但 `id[p]` 已经被改成 2，因此条件不成立，`id[1]` 没有被修改；
- `i=2`：把 `id[2]` 保持为 2。

最终得到：

```text
id = [2, 1, 2]
```

但这 3 个站点实际上应该全部连通。站点 1 仍然具有标识 1，说明算法破坏了 Quick-Find 的不变量。

### 原因

循环中动态读取 `id[p]`。第一次修改 `id[p]` 后，后续判断使用了新的标识值，导致原来属于 `p` 所在分量的元素无法全部被找到。
